# 🛡️ Women Safety App

A Flutter-based mobile application designed to provide safety features and emergency assistance for women.

## 📱 About the Project

Women Safety App is a mobile application developed using Flutter to provide users with quick access to emergency and safety-related features.

The application focuses on making emergency assistance easily accessible through a simple and user-friendly interface.

## ✨ Features

- 🚨 **Emergency SOS Assistance**
  
  When the user activates the Emergency button, the app automatically calls the two configured emergency contacts and sends them an emergency message containing the user's current location.

- 📍 **Location-Based Safety**
  
  The application uses the user's location to provide location-based emergency assistance.

- 📞 **Emergency Contact Support**
  
  Users can configure emergency contacts who can be contacted during an emergency.

- 🔥 **Firebase Integration**
  
  Firebase is used to support the application's backend-related functionality.

- 🎨 **Simple and User-Friendly UI**
  
  The application is designed with a simple interface so that important safety features can be accessed quickly.

- 📱 **Cross-Platform Flutter Application**
  
  Developed using Flutter for cross-platform mobile application development.

## 🚨 Emergency Workflow

1. User presses the **Emergency** button.
2. The app automatically calls the two configured emergency contacts.
3. The app retrieves the user's current location.
4. An automatic emergency message containing the user's location is sent to the emergency contacts.

## 🚀 Getting Started

### Prerequisites

Make sure you have the following installed:

- Flutter SDK
- Dart SDK
- Android Studio or VS Code
- Git

### Installation

Clone the repository:

```bash
git clone https://github.com/snehalterdalkar-blip/women_safety_app.git
```

Navigate to the project:

```bash
cd women_safety_app
```

Install dependencies:

```bash
flutter pub get
```

Run the application:

```bash
flutter run
```
