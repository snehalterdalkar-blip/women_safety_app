# 🛡️ Women Safety App

A Flutter-based mobile application designed to provide safety features and emergency assistance for women.

## 📱 About the Project

Women Safety App is a mobile application developed using Flutter to provide users with quick access to emergency and safety-related features.

The application focuses on making emergency assistance easily accessible through a simple and user-friendly interface.

## ✨ Features

- 🚨 Emergency SOS assistance
- 📍 Location-based safety features
- 📞 Emergency contact support
- 🔥 Firebase integration
- 🎨 Simple and user-friendly UI
- 📱 Cross-platform Flutter application

## 🛠️ Technologies Used

- **Flutter**
- **Dart**
- **Firebase**
- **Android**
- **Git & GitHub**

## 🚀 Getting Started

### Prerequisites

Make sure you have the following installed:

- Flutter SDK
- Dart SDK
- Android Studio or VS Code
- Git

### Installation

Clone the repository:

```bash
git clone https://github.com/snehalterdalkar-blip/women_safety_app.git
```

Navigate to the project:

```bash
cd women_safety_app
```

Install dependencies:

```bash
flutter pub get
```

Run the application:

```bash
flutter run
```
